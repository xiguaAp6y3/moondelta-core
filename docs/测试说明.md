# moondelta-core 测试说明（0.3.0）

本文说明如何运行与扩展本项目的测试：单元测试、互操作校验脚本、fixture 体系与验收证据的存放位置。

## 1. 单元测试（37 个具名用例）

```bash
moon test --target native        # 期望：Total tests: 37, passed: 37
moon check --target native       # 期望：0 errors
```

测试位于 `src/delta_wbtest.mbt`（白盒，同包内可直接调用内部函数），按里程碑分层：

| 分层 | 用例（摘要） |
|---|---|
| 基础读取（0.1.x） | schema 解析、action 解析、13 版本回放与时间旅行、统计剪枝（120→60、min==max 边界、无 stats）、分区表补齐与过滤、真实表读取（Databricks COVID、delta-rs table_a）、缺失数据文件、checkpoint-only 结构化拒绝 |
| 写入（0.1.x/0.1.1） | create+append+读回（int64/string）、boolean/double 回环 |
| M1 协议与工程 | reader v2/v3 拒绝、readerFeatures 兜底拒绝、删除向量拒绝、未知 action 拒绝、cdc 忽略+txn 识别、非 20 位日志名拒绝、percent-encoded path 读取、byte/short 回读、create 防重、append 列名/类型/NOT NULL 校验、put-if-absent、writer>2 拒绝、stats 损坏报错 |
| M2 嵌套读取 | list_columns.parquet 正读（[1,2,3]/[NULL,1]/[4]）、D3 engine-written 与 delta-rs oracle 逐值断言（struct/list/map + NULL/空集合/null 元素）、array 子树解析 |
| M3 checkpoint | 截断日志恢复（v10/100/100）、checkpoint-only flat 可读、checkpoint 与 JSON 回放互证（table_a v10=100 文件）、checkpoint-only-nested 5 行嵌套值 |
| M4 嵌套写入 | struct/list/map 写→读回环（与 D3 oracle 相同数据形态，含 NULL/空集合/null 元素） |

新增测试的约定：一个能力点 = 一个独立用例 + （负向行为）断言错误文本包含原因；临时表写在 `_build/test-tmp/` 下并用 `reset_dir` 清理。

## 2. 互操作校验脚本（164 项检查）

位置 `artifacts/acceptance/`，用仓库自带 Python 环境（`.tools/pyenv`，含 deltalake 1.6.6 / duckdb / pyarrow）从仓库根目录运行：

```bash
.tools/pyenv/Scripts/python.exe artifacts/acceptance/d2_verify.py      # 17 项：flat 双向对拍证据重算（哈希 79 项、protocol/stats/值）
.tools/pyenv/Scripts/python.exe artifacts/acceptance/d3_verify.py      # 40 项：nested fixture 读取与 oracle 一致、checkpoint-only 恢复、负向不冒充通过
.tools/pyenv/Scripts/python.exe artifacts/acceptance/d4_structure.py   # 27 项：申报/README/ROADMAP 文本与范围一致
.tools/pyenv/Scripts/python.exe artifacts/acceptance/d4_v3_check.py    # 65 项：补丁与文档逐条结构校验
.tools/pyenv/Scripts/python.exe artifacts/acceptance/links_hashes.py   # 15 项：README 链接与哈希抽样
```

依赖：DuckDB delta 扩展（首次运行自动 INSTALL/LOAD）；d2/d3 的 raw/ 输出是 0.1.x–0.2.x 历史证据，脚本断言的是**当前行为**并在检查名中注明。

## 3. 外部引擎回读（M4）

本项目写出的嵌套表：`artifacts/interop-nested/moondelta-nested-written/`（由 `moon run --target native src/examples/write_nested` 重新生成）。回读验证脚本逻辑（delta-rs 逐行逐字段 + DuckDB delta_scan 嵌套取值，10 项）见 `artifacts/acceptance/m4/external-readback.json` 与 `m4/README.md`。
